# Overview

Welcome to Session 9. Today we will be covering **Technical Vocabulary - Aircraft & Infrastructure**.

---

# 2.3.1 Core Concept

* **Aircraft Anatomy**: Key terms like Fuselage, Empennage, Ailerons, Flaps, and Landing Gear.
* **Airport Infrastructure**: Key terms like Tarmac, Taxiway, Apron, Gate, and Control Tower.
* **Ground Handling**: Vocabulary relating to baggage, fueling, and pushback operations.

---

# 2.3.2 Application

* **Safety**: Accurately reporting maintenance issues requires knowing the exact terminology for aircraft parts.
* **Logistics**: Ground crew must understand infrastructure terms to navigate the airport safely.
* **Documentation**: Forms and logs utilize strict technical jargon.

---

# 2.3.3 Practice

* **Diagram**: Label a blank diagram of an aircraft's anatomy.
* **Map**: Identify key infrastructure points on an airport layout map.
* **Role Play**: Report a maintenance issue to engineering using correct terminology.
