# Session 19: Principles of Paragraph Writing

---

# Overview

Welcome to Session 19. Today we will be covering **Principles of Paragraph Writing**.

---

# 4.1.1 Core Concept

* **Topic Sentence**: The first sentence that expresses the main idea of the paragraph.
* **Supporting Sentences**: Details, data, and examples that back up the topic sentence.
* **Concluding Sentence**: A wrap-up sentence that transitions to the next idea.
* **Cohesion**: Using transition words (However, Therefore, Additionally) for flow.

---

# 4.1.2 Application

* **Clarity**: Organizing thoughts logically so the reader can follow operational updates easily.
* **Professionalism**: Well-structured paragraphs reflect a structured, competent mind.
* **Brevity**: Keeping paragraphs focused on a single topic prevents rambling and confusion.

---

# 4.1.3 Practice

* **Identify**: Label the topic, supporting, and concluding sentences in a provided text.
* **Draft**: Write a 5-sentence paragraph describing a daily routine using transition words.
* **Edit**: Rewrite a rambling, unstructured paragraph into a cohesive one.
