# 4.4.1 Applying slide transitions

* **Definition:** A Transition is the visual effect that occurs when moving from one slide to the next.
* **Applying:** Transitions Tab -> Select an effect (Fade, Push, Morph).
* **Best Practice:** Stick to simple transitions like 'Fade'. Wild effects (Origami, Shatter) distract from a professional presentation.

---

# 4.4.2 Customizing transition timing and effects

* **Duration:** Controls how fast the transition happens (e.g., 1.5 seconds).
* **Advance Slide:** 
  * *On Mouse Click:* The presenter controls the pace manually.
  * *After X Seconds:* The slide automatically moves forward (used for automated kiosk displays at airports).

---

# 4.4.3 Animating text and objects (Entrance, Emphasis)

* **Definition:** Animations control how individual items (text, images) enter, act, or exit *within* a single slide.
* **Entrance (Green):** How the object appears (e.g., Fade in, Fly in).
* **Emphasis (Yellow):** Draws attention to an object already on screen (e.g., Pulse, Grow).
* **Exit (Red):** How the object leaves the screen.

---

# 4.4.4 Using the Animation Pane for sequencing

* **Animation Pane:** Animations Tab -> Animation Pane. The command center for sequencing.
* **Start Options:**
  * *On Click:* Wait for presenter to click.
  * *With Previous:* Animations happen at the exact same time.
  * *After Previous:* Animation starts automatically after the last one finishes, creating a chain reaction.

---

# 4.4.5 Best practices: Avoiding presentation fatigue

* **The 6x6 Rule:** No more than 6 bullet points per slide, no more than 6 words per line.
* **Death by PowerPoint:** Avoid reading slides verbatim. The slide is a visual aid, you are the presentation.
* **Animation Restraint:** Only animate objects if it adds explanatory value (e.g., a flowchart building step-by-step). Never animate just for decoration.

---

# 4.4.6 Hands-on: Animating a step-by-step process

* **Step 1:** Go to the 'Evacuation Procedure' SmartArt slide.
* **Step 2:** Select the SmartArt, go to Animations -> 'Fade' entrance effect.
* **Step 3:** Open Animation Pane, click Effect Options, and choose 'One by One'.
* **Step 4:** Set the animation to advance 'On Click'.
* **Step 5:** Go into Slide Show mode to test that the steps appear sequentially upon clicking.
