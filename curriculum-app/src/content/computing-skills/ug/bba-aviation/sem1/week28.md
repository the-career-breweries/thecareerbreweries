# 5.3.1 Concept of Cloud Computing and Storage

* **Definition:** Storing and accessing data and programs over the Internet instead of your computer's local hard drive.
* **Benefits:**
  * *Accessibility:* Access files from any device, anywhere in the world.
  * *Security:* Immune to your laptop crashing or being stolen.
  * *Collaboration:* Multiple people can edit the same file simultaneously.

---

# 5.3.2 Introduction to Google Drive / OneDrive

* **Google Drive / MS OneDrive:** The industry standards for cloud storage.
* **The Interface:** Similar to Windows File Explorer. You can create folders, upload files, and move things around.
* **Desktop Sync:** Apps that map your cloud storage to look like a normal folder (e.g., `C:\Users\Admin\OneDrive`). Files saved here instantly upload to the cloud.

---

# 5.3.3 Uploading, organizing, and syncing files

* **Uploading:** Drag and drop files from your desktop directly into the browser window.
* **Organizing:** Create folders (e.g., '2026 Flight Logs') and keep them structured.
* **Offline Access:** You can flag certain critical cloud files to be kept 'Available Offline' so you can work on them during a flight without Wi-Fi.

---

# 5.3.4 Sharing files and setting permission levels

* **Sharing Links:** Instead of emailing attachments, generate a shareable link.
* **Permission Levels:**
  * *Viewer:* Can read and download, but cannot make changes.
  * *Commenter:* Can leave sticky-note suggestions without altering the original text.
  * *Editor:* Has full control to delete, type, and modify the document.

---

# 5.3.5 Real-time collaboration in Docs/Sheets/Slides

* **Simultaneous Editing:** In Google Docs or Word Online, you can see your colleagues' cursors typing in real-time.
* **Version History:** The cloud tracks every keystroke. If someone accidentally deletes a paragraph, you can go to File -> Version History and restore the document to how it looked yesterday.

---

# 5.3.6 Hands-on: Co-authoring a shared document

* **Step 1:** Open Google Docs / Word Online and create a new document titled 'Group Project'.
* **Step 2:** Share the document with the person sitting next to you, giving them 'Editor' access.
* **Step 3:** Both students log in and simultaneously type your names and favorite airlines.
* **Step 4:** Try using the 'Suggesting/Reviewing' mode to leave a comment on their text.
