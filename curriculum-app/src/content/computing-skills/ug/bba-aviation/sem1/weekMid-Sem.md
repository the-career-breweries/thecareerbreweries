# 💻 CO1: Hardware vs. Software

- **Hardware:** Physical, tangible parts of the computer.
  - *Examples:* Monitor, Keyboard, RAM, Motherboard, Printer.
  - *Classification:* Input (Keyboard), Output (Monitor), Storage (Hard Disk).
  
- **Software:** A set of instructions (programs) that tell the hardware what to do.
  - **System Software:** Manages computer hardware. Provides a platform for other software. 
    - *Examples:* Operating System (Windows 11, macOS), Device Drivers.
  - **Application Software:** Designed for the user to perform specific tasks.
    - *Examples:* MS Word, Web Browser, Video Player, Airline Booking System.

---

# ⚙️ CO1: Operating Systems & File Management

- **Operating System (OS):** The master system software. 
  - *Functions:* Manages hardware/software resources, provides a user interface (UI), manages memory, handles files, and controls peripherals.
- **File Management:** 
  - **File:** A collection of data stored under a single name (e.g., `Resume.pdf`).
  - **Folder:** A directory used to store and organize files.
  - *Airline Office Context:* Efficient file management ensures passenger manifests, flight schedules, and financial reports are securely organized, easily searchable, and not accidentally deleted.

# 📄 CO2: MS Word - Document Creation

- **Save vs. Save As:**
  - **Save:** Updates an existing file with new changes.
  - **Save As:** Saves a *new* file or saves an existing file with a *new name/location/format*.
  - *File Formats:* `.docx` (Standard Word format), `.pdf` (Portable Document Format, non-editable).
- **Templates:** Pre-formatted documents used as a starting point (e.g., a Resume template). They save time and ensure professional consistency.
- **Tables:** Used to present information neatly in rows and columns (e.g., a list of subjects and marks).

---

# 👔 CO2: MS Word - Professional Resumes

**Creating a One-Page Resume:**
1. **Page Layout:** Go to the 'Layout' tab. Set Margins to 'Normal' or 'Narrow' so content fits on one page.
2. **Fonts & Headings:** Choose a professional font (e.g., Arial, Calibri). Use **Bold** and larger text sizes for your Name and Section Headings to make them stand out.
3. **Bullet Points:** Use bullets to list education, skills, and work experience cleanly.
4. **Alignment & Spacing:** Use left-alignment for main text and adjust line spacing (e.g., 1.15) for a neat, consistent look.
5. **Exporting:** Go to File > Save As, and choose **PDF** to ensure your formatting doesn't break when sharing with employers.

# 📊 CO2: MS PowerPoint - Presentations

**Creating a Presentation (5-6 Slides):**
1. **Create:** Open PowerPoint, select 'Blank Presentation' or a theme. Go to Home > New Slide to add slides.
2. **Content:** Click on the text boxes ("Click to add title" / "Click to add text") to type your content.
3. **Design:** Go to the 'Design' tab to apply a consistent theme or template.
4. **Images:** Go to Insert > Pictures to add images. Resize and format them to fit.
5. **Slide Show:** Go to the 'Slide Show' tab and click 'From Beginning' (or press F5) to present.

**Tips for Readability:**
- Use large, clear fonts (minimum 24pt).
- Keep text brief (use bullet points, not paragraphs).
- Ensure high contrast between text color and background color.
