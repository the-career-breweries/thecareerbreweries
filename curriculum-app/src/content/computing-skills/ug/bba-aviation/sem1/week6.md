# 2.1.1 Introduction to MS Word interface and Ribbon

* **The Ribbon:** The tabbed toolbar at the top (Home, Insert, Layout, etc.).
* **Quick Access Toolbar:** The top-left corner (Save, Undo, Redo).
* **The Document Area:** The digital 'paper' where you type.
* **Status Bar:** Bottom edge showing page count, word count, and zoom controls.

---

# 2.1.2 Creating, saving, and opening documents

* **Creating:** Open Word -> Click 'Blank Document' (or use `Ctrl + N`).
* **Saving for the first time (Save As):** File -> Save As -> Choose location -> Name the file. (Shortcut: `F12`).
* **Saving updates (Save):** File -> Save (Shortcut: `Ctrl + S`). Do this frequently!
* **Opening:** File -> Open -> Browse to locate an existing `.docx` file (Shortcut: `Ctrl + O`).

---

# 2.1.3 Text selection and cursor movement shortcuts

* **Selecting Text:**
  * Double-click: Selects a word.
  * Triple-click: Selects an entire paragraph.
  * `Ctrl + A`: Selects the entire document.
* **Cursor Movement:**
  * `Home` / `End`: Jump to beginning/end of the line.
  * `Ctrl + Left/Right Arrow`: Jump word by word.

---

# 2.1.4 Basic font formatting (Bold, Italic, Underline, Color)

* **Location:** Home Tab -> Font Group.
* **Font Face & Size:** Choose professional fonts (Arial, Calibri, Times New Roman) and readable sizes (11-12pt for body).
* **Emphasis Shortcuts:**
  * **Bold:** `Ctrl + B` (Use for headers or key terms)
  * *Italic:* `Ctrl + I` (Use for book titles or foreign words)
  * <u>Underline:</u> `Ctrl + U`
* **Font Color:** Use the 'A' icon with the colored underline. Stick to black/dark gray for professional docs.

---

# 2.1.5 Using Format Painter and Clear Formatting

* **Format Painter:** Copies all formatting from one piece of text and applies it to another.
  * *How to use:* Select formatted text -> Click 'Format Painter' (paintbrush icon) -> Highlight the target text.
  * *Tip:* Double-click the Format Painter to apply the format to multiple different areas.
* **Clear Formatting:** The 'A' with an eraser icon. Removes all bold, colors, and font changes, returning text to the default plain style.

# 2.1.6 Hands-on: Drafting a basic aviation memo

* **Step 1:** Open a blank document.
* **Step 2:** Type a standard memo header: TO:, FROM:, DATE:, SUBJECT:.
* **Step 3:** Use Bold on the header labels.
* **Step 4:** Write a 3-sentence body about a 'New Boarding Procedure'.
* **Step 5:** Save As `Boarding_Memo_YourName.docx`.
