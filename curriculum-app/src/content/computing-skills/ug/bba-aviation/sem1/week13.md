# 🧠 Key Concept

- Browser Basics & Evaluating Reliable Websites

- Everyday parts of a web browser:


### 🔹 Is This Website Reliable?
- Look for HTTPS and a padlock icon in the address bar, which show the connection is secure. Official sites end in recognisable domains (for example, a government or known organisation address) rather than unfamiliar or misspelled ones.
- For aviation research, official sites such as DGCA or IATA are reliable sources; random blogs with no named author or sources are not.

# 🧠 Key Concept

- Professional Email Structure & Cloud Storage Explained

- The parts of a professional email:


### 🔹 Cloud Storage
- Cloud storage (such as Google Drive or OneDrive) saves files on the internet instead of only on one computer, so they can be reached from any device and shared with others.
- Sharing permissions matter: view-only access lets someone see a file without changing it; edit access lets them make changes.

- Always check recipient address and attachment before clicking Send
- Subject line should be clear: Course + Topic + Your Name
