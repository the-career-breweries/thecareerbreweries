# 2.5.1 Using Styles for consistent document formatting

* **What are Styles?** Pre-configured combinations of font, size, color, and paragraph spacing (Home Tab -> Styles gallery).
* **Heading 1, Heading 2:** Used to structure your document hierarchically.
* **Benefits:**
  1. Consistency: All headings look exactly the same.
  2. Efficiency: Change the 'Heading 1' style once, and it updates everywhere.
  3. Navigation: Allows use of the Navigation Pane to jump between sections.

---

# 2.5.2 Generating a Table of Contents automatically

* **Prerequisite:** You *must* format your document titles using Styles (Heading 1, Heading 2) for this to work.
* **Steps:**
  1. Place cursor where you want the TOC (usually a blank page after the title).
  2. Go to References Tab -> Table of Contents.
  3. Choose an Automatic Table.
* **Updating:** If you add text and page numbers change, simply click the TOC and select 'Update Table'.

# 2.5.3 Adding cover pages and watermarks

* **Cover Pages:** Insert Tab -> Cover Page. Provides professional, pre-designed title pages (Title, Author, Date). It automatically suppresses headers/page numbers on this first page.
* **Watermarks:** Design Tab -> Watermark. Faded text or images placed behind the main document text.
  * *Common uses:* 'DRAFT', 'CONFIDENTIAL', or a faint company logo.

---

# 2.5.4 Introduction to Mail Merge for bulk letters

* **Definition:** A tool to create personalized letters/emails for many recipients using a single template and a data source (like an Excel list).
* **The Process:**
  1. Mailings Tab -> Start Mail Merge -> Letters.
  2. Select Recipients (Browse for your Excel file of names/addresses).
  3. Insert Merge Fields (e.g., `<<First_Name>>`) into your letter.
  4. Finish & Merge -> Print Documents.
