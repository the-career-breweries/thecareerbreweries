# 1.2.1 Difference between hardware and software

* **Hardware:** The physical, tangible components you can touch (Monitor, Keyboard, RAM, Motherboard).
* **Software:** The intangible set of instructions that tells the hardware what to do (Windows, MS Word, Chrome).
* **The Relationship:** Hardware is useless without software to drive it; software cannot execute without hardware.

---

# 1.2.2 Types of software: System vs Application

* **System Software:** Programs designed to run the computer's hardware and application programs.
  * *Examples:* Windows, macOS, Linux, Device Drivers.
* **Application Software:** Programs designed to help the user perform specific tasks.
  * *Examples:* Microsoft Office, Web Browsers, Aviation ERP systems.

---

# 1.2.3 Common application software used in aviation

* **Word Processors:** Microsoft Word (Drafting memos, incident reports).
* **Spreadsheets:** Microsoft Excel (Crew scheduling, budgeting, passenger manifest tracking).
* **Presentation:** Microsoft PowerPoint (Safety briefings, management meetings).
* **Industry-Specific:** Amadeus/Sabre (GDS for ticketing), Flight Dispatch software.

---

# 1.2.4 Understanding software licenses and open-source

* **Commercial/Proprietary License:** Software you must purchase. Source code is closed. (e.g., MS Office).
* **Open-Source Software (OSS):** Free to use and modify. Source code is public. (e.g., Linux, Mozilla Firefox).
* **Freeware:** Free to use, but source code is closed. (e.g., Adobe Acrobat Reader).
* **Subscription (SaaS):** Pay a monthly/annual fee for access (e.g., Microsoft 365).

---

# 1.2.5 Installing and uninstalling basic applications

* **Installing Windows Apps:**
  1. Download the installer (.exe or .msi).
  2. Double-click the file and follow the Setup Wizard.
  3. Accept the End User License Agreement (EULA) and choose the install directory.
* **Uninstalling:**
  1. Open the Start Menu and search for 'Add or remove programs'.
  2. Locate the app in the list.
  3. Click 'Uninstall' and follow prompts to cleanly remove files.

---

# 1.2.6 Hands-on: Exploring installed software in the lab

* **Step 1:** Open the Windows Start Menu.
* **Step 2:** Browse the 'All Apps' list to identify pre-installed system tools (e.g., Calculator, Notepad).
* **Step 3:** Locate productivity applications (Word, Excel).
* **Step 4:** Check the system tray (bottom right) for background software (Antivirus, Cloud Sync).
