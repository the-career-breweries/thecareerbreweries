## Key Concepts
- **Operating Systems (OS)**: System software that manages computer hardware, software resources, and provides common services for computer programs.
- **Windows UI**: The user interface of the Windows operating system, including the desktop, taskbar, start menu, and file explorer.


---

## Important Definitions
- **Operating System**: The software that supports a computer's basic functions, such as scheduling tasks, executing applications, and controlling peripherals.
- **GUI (Graphical User Interface)**: A visual way of interacting with a computer using items such as windows, icons, and menus.
