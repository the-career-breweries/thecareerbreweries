# 🧠 Key Concept

- What Is an Operating System?

- An operating system (OS) is the main piece of software that manages a computer's hardware and lets you run other programs. It starts automatically the moment a computer is switched on, and every other application (Word, a browser, a game) runs on top of it.
- Examples of operating systems: Windows and macOS (on desktops/laptops), Linux (on servers and some desktops), and Android and iOS (on phones and tablets).
- What an OS actually does:
- **Manages hardware** — talks to the keyboard, mouse, screen, printer and storage on your behalf
- **Runs application software** — opens and manages programs like Word or a browser
- **Manages memory and files** — keeps track of what is open and where files are stored
- **Provides the interface you see** — the desktop, icons, windows, and menus

- Simple analogy: the OS is like a hotel manager — it coordinates everything behind the scenes (hardware) so guests (you) can simply ask for a service (open an app) without needing to know how it works.

# 💻 Hands-on Practice

- **Part 1** — Do This in class

1. Open Start menu — find and open: Word, Excel, File Explorer, Settings
2. Use Search (Win key) — search for 'Calculator' and open it
3. Open 3 programs — arrange them side by side using Snap (Win + Left/Right arrow)
4. Practice Minimize, Maximize, and Close on each window
5. Press Alt+Tab — switch between all open programs 5 times
6. Press Win+D — show desktop; press again to restore windows
7. Open File Explorer (Win+E) — browse Desktop, Documents, Downloads

- Quick Tips
- Windows key = Start menu; Win+E = File Explorer; Win+D = show desktop
- Alt+Tab switches apps; Alt+F4 closes the active window
- Never force power off unless the PC is completely frozen
- Ask before changing display settings on class computers
- Lock PC (Win+L) when stepping away from your seat
