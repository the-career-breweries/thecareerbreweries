# 3.2.1 Number formatting (Currency, Percentages, Dates)

* **General vs Specific Formats:** Home Tab -> Number Group.
* **Currency / Accounting:** Adds a currency symbol ($, €, ₹) and two decimal places. (Accounting aligns symbols neatly on the left).
* **Percentages:** Converts a decimal to a percentage (e.g., 0.85 becomes 85%).
* **Dates:** Short Date (1/15/2026) vs Long Date (Thursday, January 15, 2026).

---

# 3.2.2 Font and border formatting

* **Font Formatting:** Standard Bold, Italic, Color options (Home Tab).
* **Borders:** By default, Excel gridlines do not print. You must add Borders (Home Tab -> Borders icon) to create visible grid tables.
  * *Common use:* Thick Outside Borders for headers, All Borders for data grids.

---

# 3.2.3 Cell alignment, Wrap Text, and Merge & Center

* **Alignment:** Align text vertically (Top, Middle, Bottom) and horizontally (Left, Center, Right).
* **Wrap Text:** Forces long text to break into multiple lines within the same cell, expanding the row height instead of bleeding into the next column.
* **Merge & Center:** Combines multiple selected cells into one large cell and centers the text. *Warning: Avoid merging data cells, only use for Titles.*

---

# 3.2.4 Adjusting row height and column width

* **Manual Adjustment:** Hover between column letters (e.g., between A and B). Click and drag the double-arrow to resize.
* **AutoFit:** Double-click the boundary between column letters. Excel automatically resizes the column to perfectly fit the longest text inside it.
* **Uniform Sizing:** Select multiple columns, then resize one; all selected columns will snap to that exact width.

---

# 3.2.5 Inserting/deleting rows, columns, and sheets

* **Inserting:** Right-click a row number -> Insert (adds a new row *above*). Right-click a column letter -> Insert (adds a column to the *left*).
* **Deleting:** Right-click the header -> Delete.
* **Hiding:** Right-click -> Hide. Useful to temporarily remove columns from view without deleting the data. (Right-click surrounding headers -> Unhide to restore).

# 3.2.6 Hands-on: Formatting a ticketing sales report

* **Step 1:** Open the raw `Sales_Report`.
* **Step 2:** Merge & Center the main title across columns A-E. Make it Bold and 16pt.
* **Step 3:** Select the 'Revenue' column and format it as Currency.
* **Step 4:** Select the header row, Apply Wrap Text, Bold, and a light blue background color.
* **Step 5:** AutoFit all columns and add 'All Borders'.
