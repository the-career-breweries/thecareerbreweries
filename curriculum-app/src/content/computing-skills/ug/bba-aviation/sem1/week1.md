# 🧠 Key Concept

- Hardware vs Software

- Every computer system is made up of two parts that work together:


### 🔹 Hardware
- **The physical parts of a computer** — anything you can see and touch.
- Monitor
- Keyboard and mouse
- System unit / CPU cabinet
- Printer
- Speakers
- Hard disk or SSD (storage)


### 🔹 Software
- The programs and instructions that tell hardware what to do. You can see software running on screen, but you cannot touch it.
- Windows (operating system)
- Microsoft Word
- Google Chrome (browser)
- Calculator app
- Video games

- Remember it this way: hardware is the body of a computer; software is the mind that tells the body what to do. Neither works without the other.

---

# 🧠 Key Concept

- **Inside the Computer** — CPU, RAM & Storage

- **CPU (Central Processing Unit)** — the “brain” of the computer. It carries out calculations and follows instructions. Example: Intel Core i5, AMD Ryzen 5.
- **RAM (Random Access Memory)** — short-term, temporary memory used only while the computer is on. It holds the programs and files in use right now, and is cleared when the computer shuts down. Example: 8 GB RAM lets several programs run smoothly together.
- **Storage (HDD / SSD)** — long-term memory that keeps files, photos and programs safely, even after the power is switched off.

# 🧠 Key Concept

- Input vs Output Devices

- Devices connect people to a computer by moving data in two directions:


### 🔹 Input Devices
- Devices that send data INTO the computer.
- **Keyboard** — typing text
- **Mouse** — pointing and clicking
- **Scanner** — digitising a paper document
- **Microphone** — recording sound
- **Webcam** — capturing video


### 🔹 Output Devices
- Devices that send data OUT of the computer so people can see, hear or print the result.
- **Monitor** — displaying images and text
- **Printer** — producing a paper copy
- **Speakers / headphones** — playing sound
- **Projector** — showing the screen on a larger surface

- Some devices do both jobs: a touchscreen accepts taps (input) and displays images (output); a network card both sends and receives data.
