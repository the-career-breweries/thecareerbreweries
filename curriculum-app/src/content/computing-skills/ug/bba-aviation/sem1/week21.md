# 4.1.1 The PowerPoint interface and workspace

* **Thumbnails Pane:** The left sidebar showing miniature versions of all slides.
* **Slide Pane:** The large central area where you edit the active slide.
* **Notes Pane:** Hidden at the bottom; used for speaker notes that the audience won't see.
* **Views:** Normal View (editing), Slide Sorter (rearranging), Reading/Slide Show View (presenting).

---

# 4.1.2 Creating a new blank presentation

* **Creation:** File -> New -> Blank Presentation (Shortcut: `Ctrl + N`).
* **Title Slide:** The default first slide. Enter the presentation title and speaker name.
* **Saving:** File -> Save As (`F12`). Save early and often. `Ctrl + S` updates the save.

---

# 4.1.3 Adding, duplicating, and deleting slides

* **New Slide (`Ctrl + M`):** Home Tab -> New Slide. (Note: `Ctrl + N` makes a new file, `Ctrl + M` makes a new slide).
* **Duplicating (`Ctrl + D`):** Instantly creates an exact copy of the selected slide. Great for keeping complex layouts consistent.
* **Deleting:** Click the slide thumbnail and press `Delete` or `Backspace`.

---

# 4.1.4 Understanding different slide layouts

* **Definition:** Pre-arranged layouts of placeholders (Title and Content, Two Content, Picture with Caption).
* **Changing Layouts:** Home Tab -> Layout. 
* **Why use them?** Layouts keep formatting consistent and ensure that when you apply a design theme, the text moves to the correct spot automatically. Do not just insert random text boxes!

---

# 4.1.5 Adding and formatting text in placeholders

* **Placeholders:** The dotted boxes that say 'Click to add text'.
* **Bullet Points:** The default text format in PowerPoint. 
  * *Tip:* Press `Tab` to indent a bullet point (sub-point), and `Shift + Tab` to outdent it.
* **Formatting Text:** Identical to MS Word (Font, Size, Bold, Color). Maintain high contrast (dark text on light backgrounds or vice versa).
