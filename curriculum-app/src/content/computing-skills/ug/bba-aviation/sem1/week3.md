# 1.3.1 Introduction to Operating Systems (Windows)

* **Definition:** An OS acts as an intermediary between the user and the computer hardware.
* **Functions:** Memory management, process management, file management, and hardware abstraction.
* **Windows OS:** The dominant OS in enterprise environments, known for its Graphical User Interface (GUI).

---

# 1.3.2 Navigating the desktop, taskbar, and start menu

* **Desktop:** The main workspace where shortcuts and files are kept.
* **Taskbar:** The bar at the bottom showing running apps and pinned shortcuts.
* **Start Menu:** The central hub for launching applications, accessing settings, and shutting down.
* **System Tray:** Located on the far right of the taskbar; shows network, battery, volume, and clock.

---

# 1.3.3 Managing windows (minimize, maximize, snap)

* **Minimize:** Hides the window to the taskbar without closing it (Shortcut: Win + Down Arrow).
* **Maximize:** Expands the window to fill the entire screen (Shortcut: Win + Up Arrow).
* **Restore/Resize:** Drag the edges or corners of a window to manually adjust its size.
* **Snap Assist:** Drag a window to the left/right edge of the screen to snap it to exactly half the monitor. Great for multitasking.

---

# 1.3.4 Customizing system settings and display

* **Accessing Settings:** Press `Win + I` or click the gear icon in the Start Menu.
* **Display Settings:** Right-click the desktop -> Display settings. Here you can change screen resolution and scale (text size).
* **Personalization:** Right-click the desktop -> Personalize. Change background wallpaper, themes, and lock screen.
* **Sound & Network:** Managed via the Settings app to connect to Wi-Fi or change output devices.

---

# 1.3.5 Understanding user accounts and security

* **Administrator Accounts:** Full control over the system. Can install software and change system-wide settings.
* **Standard User:** Can use apps and save files, but cannot make system-level changes. Best for daily security.
* **UAC (User Account Control):** The prompt that asks 'Do you want to allow this app to make changes?'. It prevents unauthorized background installations.

---

# 1.3.6 Hands-on: Personalizing the OS environment

* **Step 1:** Right-click the Desktop and select 'Personalize'.
* **Step 2:** Change the background image to a solid color.
* **Step 3:** Go to 'Themes' and switch between Light and Dark mode.
* **Step 4:** Right-click the Taskbar, select 'Taskbar settings', and toggle 'Automatically hide the taskbar'.
