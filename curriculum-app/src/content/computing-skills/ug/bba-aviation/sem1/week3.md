## Key Concepts
- **File System Organization**: The logical structuring of files into directories and subdirectories for easy retrieval.
- **File Explorer Search**: Using built-in search tools to locate files quickly.


---

## Important Definitions
- **Folder/Directory**: A storage space where many files can be placed into groups and organize the computer.
- **File Extension**: The suffix at the end of a filename (e.g., .docx, .pdf) that indicates the file type.


---

## Mnemonic: COPS
- C - Create
- O - Organize
- P - Protect
- S - Search
