# 1.4.1 Understanding the file system hierarchy

* **Drives:** The root storage locations (e.g., C: for OS, D: for Data).
* **Directories/Folders:** Containers used to organize files logically.
* **Subfolders:** Folders nested inside other folders (e.g., `C:\Aviation\Manifests\2026`).
* **File Paths:** The exact address of a file on the computer (e.g., `C:\Users\Admin\Documents\report.docx`).

---

# 1.4.2 Creating, renaming, and deleting folders

* **Creating a Folder:** Right-click empty space -> New -> Folder. Type a name and press Enter.
* **Renaming:** Right-click the file/folder -> Rename (or click it and press `F2`). Use clear, descriptive names.
* **Deleting:** Right-click -> Delete (or press `Del`). 
* **Recycle Bin:** Deleted files go here first. You can restore them unless you empty the bin (or use `Shift + Del` to permanently delete).

---

# 1.4.3 Moving and copying files (Cut, Copy, Paste)

* **Copy (Ctrl + C):** Duplicates the file. The original stays in place.
* **Cut (Ctrl + X):** Prepares the file to be moved. The original will be removed once pasted.
* **Paste (Ctrl + V):** Places the copied or cut file into the new destination folder.
* **Drag and Drop:** Clicking and dragging a file to a new folder. (Holding Ctrl while dragging forces a copy).

---

# 1.4.4 File extensions and default applications

* **Definition:** The 3 or 4 letters after the dot in a filename, indicating the file format.
* **Common Extensions:**
  * Document: `.docx`, `.pdf`, `.txt`
  * Image: `.jpg`, `.png`
  * Spreadsheet: `.xlsx`, `.csv`
* **Default Apps:** Windows uses the extension to know which app to open. (e.g., `.docx` opens MS Word). You can change this via 'Open with...'.

---

# 1.4.5 Searching for files and using filters

* **Windows Search:** Use the search bar in the Taskbar or top right of File Explorer.
* **Filters:** You can narrow down searches by type, date modified, or size.
  * *Example:* Search `kind:pdf` to only find PDF documents.
  * *Example:* Search `datemodified:today` to find recent work.
* **Wildcards:** Use `*` to represent any text. E.g., `*.xlsx` finds all Excel files.
