## Key Concepts
- **Hardware vs Software**: Hardware refers to the physical components of a computer, while software refers to the programs and operating systems that run on it.
- **Input/Output Devices**: Tools used to send data to a computer (input) and receive data from a computer (output).


---

## Important Definitions
- **CPU (Central Processing Unit)**: The primary component of a computer that acts as its 'brain', performing most of the processing.
- **RAM (Random Access Memory)**: A form of computer memory that can be read and changed in any order, typically used to store working data and machine code.


---

## Mnemonic: IPOS
- I - Input (Keyboard, Mouse)
- P - Process (CPU, RAM)
- O - Output (Monitor, Printer)
- S - Storage (Hard Drive, SSD)
