# 1.1.1 Introduction to computing devices and lab safety

* **Definition:** A computer is an electronic device that processes data into meaningful information.
* **Key Components:** Hardware (physical parts) and Software (programs).
* **Lab Safety:**
  1. No food or beverages near the workstations.
  2. Ensure all cables are securely plugged in.
  3. Always log off or shut down properly before leaving.
  4. Do not attempt to repair hardware issues yourself; notify the IT admin.

---

# 1.1.2 Identifying central processing units (CPU) and memory

* **CPU (Central Processing Unit):** The 'brain' of the computer.
  * **ALU (Arithmetic Logic Unit):** Performs math and logical operations.
  * **CU (Control Unit):** Directs the flow of data.
* **Memory (RAM vs ROM):**
  * **RAM (Random Access Memory):** Temporary, volatile storage for active tasks. Cleared on shutdown.
  * **ROM (Read-Only Memory):** Non-volatile, holds boot instructions.

---

# 1.1.3 Exploring input devices (keyboard, mouse, scanners)

* **Purpose:** Input devices allow users to send data and control signals to the computer.
* **Keyboard:** Used for text entry and command shortcuts (e.g., Ctrl+C, Ctrl+V).
* **Mouse/Touchpad:** Pointing devices for GUI navigation (click, double-click, drag-and-drop).
* **Scanners:** Converts physical documents into digital formats (PDF, JPEG) used in aviation admin.

---

# 1.1.4 Exploring output devices (monitors, printers)

* **Purpose:** Output devices translate processed digital data into human-readable form.
* **Monitors:** Visual display. Measured in resolution (e.g., 1080p, 4K) and refresh rate.
* **Printers:** 
  * *Laser Printers:* Fast, uses toner, best for high-volume text.
  * *Inkjet Printers:* Uses liquid ink, best for photos/color.
  * *Thermal Printers:* Used for boarding passes and luggage tags.

---

# 1.1.5 Understanding storage devices (HDD, SSD, USB)

* **Purpose:** Long-term, non-volatile data retention.
* **HDD (Hard Disk Drive):** Uses magnetic spinning platters. Cheaper, higher capacity, but slower and fragile.
* **SSD (Solid State Drive):** Uses flash memory. No moving parts, much faster boot/load times, more durable.
* **USB Flash Drives:** Portable flash memory for transferring files between disconnected devices.

---

# 1.1.6 Hands-on: Examining hardware components

* **Step 1:** Observe the external ports (USB, HDMI, Ethernet).
* **Step 2:** Identify the power supply unit and cooling fans.
* **Step 3:** Locate the motherboard, CPU cooler, and RAM slots.
* **Step 4:** Note how storage drives (SATA/NVMe) are connected.
* **Safety Warning:** Always ground yourself before touching internal components to prevent static discharge.
