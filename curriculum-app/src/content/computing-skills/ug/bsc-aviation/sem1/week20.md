# 3.10.1 Page layout, orientation, and scaling

* **Page Layout View:** View Tab -> Page Layout. Shows exactly where the page breaks will cut your data.
* **Orientation:** Switch to Landscape (Page Layout Tab) for wide spreadsheets with many columns.
* **Scaling (Fit to Page):** Page Layout Tab -> Scale to Fit. 
  * *Pro Tip:* Set Width to '1 page' to force all columns onto one page, letting the rows flow naturally to page 2.

---

# 3.10.2 Setting print areas and page breaks

* **Print Area:** Highlights only a specific part of a massive spreadsheet to print. (Select cells -> Page Layout -> Print Area -> Set Print Area).
* **Page Breaks:** Insert manual breaks to force specific sections onto a new page (Page Layout -> Breaks -> Insert Page Break).

---

# 3.10.3 Repeating rows/columns as print titles

* **The Problem:** When printing a 5-page list, pages 2-5 will just have raw numbers with no header row to explain what the columns mean.
* **The Solution:** Page Layout Tab -> Print Titles.
* **Steps:** Click 'Rows to repeat at top' -> Click Row 1 -> OK. Now Row 1 prints at the top of every physical page.

---

# 3.10.4 Adding headers and footers in Excel

* **Access:** View Tab -> Page Layout view. Click in the header/footer zones.
* **Dynamic Elements:** Header & Footer tools allow you to insert dynamic codes like `&[Page]` (current page number), `&[Date]` (today's date), and `&[File]` (the filename).
* **Best Practice:** Always put page numbers in the footer of multi-page spreadsheets.
