# 🧠 Key Concept

- Character Formatting vs Paragraph Formatting


### 🔹 Character Formatting
- Applies to selected letters or words only — it changes how the text itself looks.
- Bold, Italic, Underline
- Font (typeface, e.g. Calibri, Arial)
- Font size and font colour


### 🔹 Paragraph Formatting
- Applies to a whole paragraph, even if just the cursor is placed inside it — it changes how the block of text is arranged.
- Alignment (Left, Centre, Right, Justify)
- Line and paragraph spacing
- Bullets and numbering

- Simple rule: select specific text to change how it looks (character); click anywhere inside a paragraph to change how it is laid out (paragraph).

---

# 🧠 Key Concept

- Styles Explained (and Format Painter)

- A Style is a saved, reusable combination of formatting (font, size, colour, spacing) that can be applied to text in one click — for example, Heading 1, Heading 2, or Normal.
- Why styles matter: they keep formatting consistent throughout a document, and if a style is changed, every piece of text using that style updates automatically.

- Copies all formatting from one piece of text and applies it to another, saving time compared to manually reapplying every setting.

- Format Painter (brush icon) copies formatting in one click
