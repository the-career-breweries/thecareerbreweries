# 1.5.1 Basic system troubleshooting (Task Manager)

* **Opening Task Manager:** Press `Ctrl + Shift + Esc`.
* **Processes Tab:** Shows all running apps and background processes. Useful for identifying what is slowing down the PC.
* **Performance Tab:** Shows real-time usage graphs for CPU, Memory, Disk, and Network.
* **Force Quitting:** If an app is 'Not Responding', right-click it in the Processes tab and select 'End Task'.

---

# 1.5.2 Safely connecting and disconnecting peripherals

* **USB Devices (Plug & Play):** Most modern mice, keyboards, and flash drives can be plugged in and used immediately.
* **Safe Removal:** For storage devices (USB drives, external HDDs), you must safely eject them to prevent data corruption.
  * *Steps:* Click the USB icon in the System Tray -> 'Eject [Device Name]' -> Wait for the 'Safe to Remove' notification.

---

# 1.5.3 Using built-in diagnostic tools

* **Disk Cleanup:** Removes temporary files, system cache, and empties the recycle bin to free up space.
* **Windows Defender / Security:** Built-in antivirus. Run a 'Quick Scan' if the system is acting suspiciously.
* **Windows Update:** Regularly checking for updates ensures security patches and bug fixes are applied.

---

# 1.5.4 Best practices for file backups

* **The 3-2-1 Rule:** Keep 3 copies of your data, on 2 different media types, with 1 copy off-site (cloud).
* **Local Backups:** Copying critical files to an external Hard Drive or USB.
* **Cloud Backups:** Using OneDrive or Google Drive to automatically sync your 'Documents' folder to the cloud. Protects against hardware failure.
