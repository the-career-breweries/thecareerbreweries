# 3.8.1 Importance of data visualization

* **Why visualize?** Humans process visual patterns much faster than raw grids of numbers.
* **Data Storytelling:** Charts highlight trends, outliers, and comparisons to help management make quick decisions.
* **Rule of Thumb:** Keep charts clean. Remove unnecessary gridlines, excessive colors, and distracting 3D effects.

---

# 3.8.2 Creating Column and Bar charts

* **Column Charts (Vertical):** Best for comparing different categories side-by-side (e.g., Revenue by Quarter).
* **Bar Charts (Horizontal):** Best when category names are very long and wouldn't fit well horizontally.
* **How to create:** Highlight your data (including labels) -> Insert Tab -> Recommended Charts -> Select Column/Bar.

---

# 3.8.3 Creating Pie and Line charts

* **Pie Charts:** Best for showing parts of a whole (percentages that add up to 100%).
  * *Limitation:* Never use a pie chart if you have more than 5 categories (it becomes unreadable).
* **Line Charts:** Best for showing trends over time (e.g., Daily passenger volume over a month).
  * *Rule:* Time should always be on the horizontal X-axis.

---

# 3.8.4 Formatting chart elements (Titles, Legends, Labels)

* **Chart Title:** Must be descriptive (e.g., "Q3 Passenger Growth" not just "Chart").
* **Data Labels:** Numbers appearing directly on the bars or pie slices so users don't have to guess the exact value.
* **Legends:** The key telling you what colors mean. Move it to the top or bottom for better layout.
* **Access:** Click the Chart -> Click the green '+' icon on the top right corner of the chart.

---

# 3.8.5 Changing chart types and source data

* **Changing Type:** Chart Design Tab -> Change Chart Type. Instantly swap a Column chart for a Line chart to see which looks better.
* **Select Data:** Right-click chart -> Select Data. Use this to add new data series (lines) to an existing chart, or fix labels if Excel guessed incorrectly.
* **Switch Row/Column:** Swaps the X-axis data with the Legend data.

# 3.8.6 Hands-on: Visualizing quarterly revenue

* **Step 1:** Select a small table of 'Monthly Revenue' data.
* **Step 2:** Insert a 2D Line Chart to show the trend over the year.
* **Step 3:** Add Data Labels and remove gridlines for a cleaner look.
* **Step 4:** Change the Chart Title to '2026 Monthly Revenue Trend'.
* **Step 5:** Move the chart to a dedicated 'Dashboard' worksheet.
