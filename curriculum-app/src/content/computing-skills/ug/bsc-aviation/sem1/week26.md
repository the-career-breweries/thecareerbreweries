# 5.1.1 Introduction to the Internet and WWW

* **The Internet:** The global network of connected computers and servers.
* **The WWW (World Wide Web):** The collection of webpages and documents accessed *via* the Internet.
* **HTTP/HTTPS:** The protocol used to transfer web pages. The 'S' stands for Secure (encrypted data).

---

# 5.1.2 Using web browsers (Chrome, Edge, Firefox)

* **Web Browsers:** Software applications used to access and view websites (Google Chrome, MS Edge, Mozilla Firefox, Safari).
* **Tabs vs Windows:** Use tabs (`Ctrl + T`) to open multiple pages within one browser window for better resource management.
* **Incognito/Private Browsing:** Opens a window that does not save history, cookies, or form data. Useful for using public computers.

---

# 5.1.3 Understanding URLs and domains

* **URL (Uniform Resource Locator):** The web address (e.g., `https://www.google.com/images`).
* **Domain Names:** The readable name of the website (e.g., `google.com`).
* **Top-Level Domains (TLDs):** Indicates the site's purpose or origin (`.com` for commercial, `.edu` for education, `.gov` for government, `.aero` for aviation).

---

# 5.1.4 Effective search engine techniques

* **Keywords:** Use concise noun phrases rather than full sentences.
* **Search Operators:**
  * *Quotes (`""`):* Forces exact match (e.g., `"Boeing 737 Max"`).
  * *Minus (`-`):* Excludes a word (e.g., `Aviation jobs -pilot`).
  * *Site limit (`site:`):* Searches within one specific website (e.g., `site:faa.gov safety regulations`).

---

# 5.1.5 Managing bookmarks and browsing history

* **Bookmarks/Favorites (`Ctrl + D`):** Saves a website URL for quick access later.
* **Bookmark Manager:** Organize saved sites into folders (e.g., 'Aviation News', 'Flight Trackers').
* **Browsing History (`Ctrl + H`):** View previously visited pages. Regularly clear your cache and cookies if websites are behaving incorrectly.

---

# 5.1.6 Hands-on: Researching aviation industry trends

* **Step 1:** Open Chrome and create a new Bookmark Folder named 'Aviation Research'.
* **Step 2:** Use the `site:` operator to search for recent press releases on `boeing.com`.
* **Step 3:** Find a relevant article and bookmark it into your new folder.
* **Step 4:** Open an Incognito window and verify that your browsing history is empty.
