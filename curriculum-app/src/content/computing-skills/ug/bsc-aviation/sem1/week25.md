# 4.5.1 Adding speaker notes to slides

* **Speaker Notes:** The section beneath the slide in Normal View. 
* **Purpose:** Write your script or key reminders here. The audience will never see these on the projector.
* **Printing Notes:** File -> Print -> Print Layout: 'Notes Pages'. Prints a thumbnail of the slide with your notes underneath.

---

# 4.5.2 Setting up the slideshow and using Presenter View

* **Slide Show Tab:** Click 'From Beginning' (`F5`) or 'From Current Slide' (`Shift + F5`).
* **Presenter View:** The ultimate tool for speakers. 
  * *Audience sees:* Only the full-screen slide on the projector.
  * *You see on your laptop:* The current slide, your secret speaker notes, a timer, and a preview of the *next* slide so you can seamlessly transition.

---

# 4.5.3 Printing handouts and notes pages

* **Handouts:** File -> Print -> Print Layout: 'Handouts'.
* **Options:** You can print 3, 4, or 6 slides per page to save paper. 
* **'3 Slides' Option:** The most popular handout format, as it prints thumbnails on the left and blank lines on the right for audience note-taking.

---

# 4.5.4 Exporting presentations to PDF or Video

* **Exporting to PDF:** File -> Save As -> `.pdf`. Great for emailing slides to clients securely without them messing up the fonts/formatting.
* **Exporting to Video:** File -> Export -> Create a Video. Turns your timed animations and recorded voiceovers into an MP4 file.
