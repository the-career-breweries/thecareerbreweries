# 🧠 Key Concept

- Files, Folders & Extensions Explained

- **A file is a single saved item of data** — a document, photo, song or program. A folder is a container used to organise files, similar to a physical folder in a filing cabinet — it can hold files and other folders inside it.
- A file extension is the short suffix after the dot in a file name (for example, .docx). It tells Windows what type of content the file holds and which program should open it.

# 🧠 Key Concept

- Copy vs Move, and the Recycle Bin

- COPY (Ctrl+C, Ctrl+V)
- Duplicates a file. The original stays exactly where it was, and a second, identical copy is placed in the new location — two copies now exist.
- Like photocopying a page: you keep the original and also get a copy.

- MOVE (Ctrl+X, Ctrl+V)
- Relocates a file. It is removed from its original location and placed in the new one — only one copy exists, just in a different place.
- Like moving a physical folder to a different drawer in a cabinet.


### 🔹 The Recycle Bin
- A temporary holding area for deleted files. A deleted file can still be restored from the Recycle Bin until it is emptied (or the file is removed with Shift+Delete), after which it is permanently gone.
