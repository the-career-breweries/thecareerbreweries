# 2.3.1 Inserting and drawing tables

* **Inserting a Table:** Insert Tab -> Table. Drag your mouse over the grid to choose columns x rows (e.g., 3x4).
* **Drawing a Table:** Insert -> Table -> Draw Table. Gives you a pencil tool to draw custom rows/columns manually (useful for complex forms).
* **Navigation:** Use `Tab` to move to the next cell. Pressing `Tab` in the very last cell automatically creates a new row.

---

# 2.3.2 Adding/deleting rows and columns

* **Adding:** 
  * Right-click inside a cell -> Insert -> Choose Insert Rows Above/Below or Columns Left/Right.
  * Or, click the '+' sign that appears when you hover over the border between rows/columns.
* **Deleting:**
  * Select the rows/columns -> Right-click -> Delete Rows/Columns. (Pressing `Backspace` deletes the row; pressing `Delete` only clears the text inside).

---

# 2.3.3 Merging and splitting cells

* **Merging Cells:** Combines two or more adjacent cells into one large cell. 
  * *Usage:* Creating a single title header across multiple columns.
  * *Steps:* Highlight cells -> Right-click -> Merge Cells.
* **Splitting Cells:** Divides a single cell into multiple new columns or rows.
  * *Steps:* Right-click cell -> Split Cells -> Choose number of columns/rows.

---

# 2.3.4 Applying table styles and shading

* **Table Design Tab:** Appears only when you click inside a table.
* **Table Styles:** Pre-formatted color schemes. Select the table -> Table Design -> Click the drop-down gallery to pick a professional style.
* **Shading:** Manually fill a specific cell with color (e.g., highlighting a total row).
* **Borders:** Add, remove, or thicken the lines around cells. Useful for creating invisible tables for layout purposes.

---

# 2.3.5 Inserting images, shapes, and SmartArt

* **Images:** Insert -> Pictures. You can insert from your device or online.
  * *Wrap Text:* Crucial step! Click the image -> Wrap Text (e.g., 'Square' or 'Tight') to allow text to flow around the image.
* **Shapes:** Insert -> Shapes. Great for drawing arrows or callout boxes.
* **SmartArt:** Insert -> SmartArt. Instantly creates professional graphics like organizational charts, process flows, and cycle diagrams.

# 2.3.6 Hands-on: Creating a flight schedule table

* **Step 1:** Create a 4x5 table. 
* **Step 2:** Label headers: Flight No, Destination, Departure Time, Gate.
* **Step 3:** Apply a professional Blue 'Table Style' with a dark header row.
* **Step 4:** Merge the top row to add a master title: "Morning Departures".
* **Step 5:** Insert a small airplane icon (Insert -> Icons) next to the master title.
