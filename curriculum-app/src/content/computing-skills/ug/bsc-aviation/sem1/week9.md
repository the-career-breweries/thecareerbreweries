# 2.4.1 Setting page margins, orientation, and size

* **Location:** Layout Tab.
* **Margins:** The blank space around the edges of the page. Standard is 1 inch. Use 'Narrow' to fit more data, or 'Custom' for letterheads.
* **Orientation:** 
  * *Portrait:* Vertical (Standard for documents).
  * *Landscape:* Horizontal (Better for wide tables or certificates).
* **Size:** Standard is A4 (international) or Letter (US). Must match your physical printer paper.

---

# 2.4.2 Adding headers, footers, and page numbers

* **Headers & Footers:** Text that repeats at the top (Header) or bottom (Footer) of every page. 
  * *Usage:* Company logos, document titles, confidentiality notices.
  * *Access:* Double-click the very top or bottom blank edge of the page.
* **Page Numbers:** Insert Tab -> Page Number. Can be placed top, bottom, or in the margins. You can set them to not appear on the title page.

---

# 2.4.3 Using page breaks and section breaks

* **Page Break (`Ctrl + Enter`):** Forces text immediately to the start of the next page. *Never* use repeated 'Enters' to get to a new page!
* **Section Break:** Layout Tab -> Breaks -> Section Break (Next Page). 
  * *Why?* Section breaks allow you to change formatting for just one part of the document (e.g., making page 2 Landscape while page 1 stays Portrait).

---

# 2.4.4 Spelling & Grammar check and Thesaurus

* **Spelling (Red squiggly line):** Indicates a misspelled word.
* **Grammar (Blue/Double-blue line):** Indicates grammatical errors or phrasing issues.
* **Review Tab -> Spelling & Grammar:** Runs a full check on the document.
* **Thesaurus:** Select a word -> Shift + F7. Provides synonyms to elevate your professional vocabulary.

---

# 2.4.5 Print preview and printing options (PDF export)

* **Print Preview:** File -> Print (Shortcut: `Ctrl + P`). Shows exactly how the document will look on paper.
* **Print Settings:** Choose which printer, print range (e.g., Pages 1-3), single/double-sided, and collation.
* **Export to PDF:** File -> Save As -> Change file type to `.pdf`. 
  * *Why PDF?* Locks the formatting so it looks identical on any device and cannot be easily edited.

---

# 2.4.6 Hands-on: Formatting a multi-page incident report

* **Step 1:** Open the drafted Incident Report.
* **Step 2:** Insert a Page Break before the 'Appendices' section.
* **Step 3:** Add a Header with the text 'CONFIDENTIAL - Internal Use Only'.
* **Step 4:** Add Page Numbers to the bottom right of the Footer.
* **Step 5:** Run a Spelling & Grammar check, then Export as a PDF.
