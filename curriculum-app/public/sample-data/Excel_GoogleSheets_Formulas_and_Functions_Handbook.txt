PART 1: FORMULA BASICS, OPERATORS & CELL REFERENCING
--------------------------------------------------------------------------------

1. FORMULA SYNTAX RULES:
   - Every formula and function MUST start with an equals sign (=).
   - Functions follow the pattern: =FUNCTION_NAME(argument1, argument2, ...)
   - Arguments are separated by commas (,).
   - Text strings inside formulas must be wrapped in double quotes: "Delayed".
   - Numerical values and cell references do NOT use quotes: A1 + 50.

2. ARITHMETIC OPERATORS & PEMDAS ORDER OF PRECEDENCE:
   +  Addition          =A1 + B1
   -  Subtraction       =A1 - B1
   *  Multiplication    =A1 * B1
   /  Division          =A1 / B1
   ^  Exponentiation    =A1 ^ 2   (A1 squared)
   %  Percentage        =A1 * 18% (Multiplies by 0.18)
   () Parentheses       Controls calculation order (e.g. =(A1+B1)*C1 )
   * PEMDAS Order: Parentheses -> Exponents -> Mult/Div -> Add/Sub

3. CELL REFERENCING TYPES (CRITICAL LAB SKILL):
   - Relative Reference (A1):
     Shifts row and column automatically when copied/dragged down or across.
     Example: In C1, =A1*B1. Dragged to C2 becomes =A2*B2.
   - Absolute Reference ($A$1):
     Locks BOTH column and row. Never changes when copied anywhere.
     Shortcut Key: Press F4 (or Fn + F4) while cursor is on cell reference.
     Example: =B2 * $D$1 (where D1 contains a fixed Tax Rate or Fuel Price).
   - Mixed Reference ($A1 or A$1):
     $A1 locks Column A, but row changes when dragged vertically.
     A$1 locks Row 1, but column changes when dragged horizontally.

4. ERROR CODES & DIAGNOSTIC FIXES:
   - #DIV/0!  : Attempted division by zero or an empty cell.
   - #N/A     : Value not available (lookup function found no match).
   - #VALUE!  : Wrong data type passed (e.g. attempting to multiply text: "A" * 5).
   - #REF!    : Invalid cell reference (a referenced row/column was deleted).
   - #NAME?   : Misspelled function name (e.g. =SUMM(A1:A10) instead of =SUM).
   - ####     : Column is too narrow to display number (double-click header edge).

PART 3: LOGICAL, COMPARISON & CONDITIONAL FUNCTIONS
--------------------------------------------------------------------------------

Comparison Operators:
= (Equal), <> (Not Equal), > (Greater Than), < (Less Than), >= (GTE), <= (LTE)

1. IF Function (Binary Decision):
   Syntax: =IF(logical_test, value_if_true, value_if_false)
   Example:
   =IF(L2 > 15, "Delayed", "On-Time")

2. Nested IF (Multi-tier Decision):
   Syntax: =IF(condition1, val1, IF(condition2, val2, val3))
   Example (Flight delay severity categorization):
   =IF(L2=0, "On-Time", IF(L2<=30, "Minor Delay", "Severe Delay"))

3. IFS Function (Modern cleaner multi-condition without nesting):
   Syntax: =IFS(condition1, val1, condition2, val2, [TRUE, default_val])
   Example:
   =IFS(L2=0, "On-Time", L2<=15, "Short Delay", L2<=60, "Moderate", TRUE, "Critical")

4. AND & OR Functions:
   - AND(cond1, cond2, ...): Returns TRUE only if ALL conditions are TRUE.
     Example: =IF(AND(F2="International", I2>250), "Heavy Widebody", "Standard")
   - OR(cond1, cond2, ...): Returns TRUE if AT LEAST ONE condition is TRUE.
     Example: =IF(OR(K2="Delayed", K2="Cancelled"), "Disrupted", "Normal")

5. IFERROR & IFNA (Error Handling):
   Syntax: =IFERROR(value, value_if_error)
   Protects sheets from displaying unsightly error codes like #DIV/0! or #N/A.
   Example:
   =IFERROR(I2 / H2, 0)   (Calculates Load Factor; returns 0 if capacity is 0)

PART 4: CRITERIA-BASED AGGREGATION FUNCTIONS (SUMIF, COUNTIF, AVERAGEIF)
--------------------------------------------------------------------------------

1. COUNTIF & COUNTIFS:
   - Single Condition: =COUNTIF(range, criteria)
     Example: =COUNTIF(B2:B51, "IndiGo")
     Example: =COUNTIF(L2:L51, ">30")
   - Multiple Conditions: =COUNTIFS(criteria_range1, crit1, criteria_range2, crit2, ...)
     Example: =COUNTIFS(B2:B51, "Air India", K2:K51, "Delayed")

2. SUMIF & SUMIFS:
   - Single Condition: =SUMIF(criteria_range, criteria, [sum_range])
     Example: =SUMIF(C2:C51, "T1", J2:J51)
     (Sums Baggage_Pcs in column J only for flights where Terminal in C is "T1")
   - Multiple Conditions: =SUMIFS(sum_range, criteria_range1, crit1, criteria_range2, crit2, ...)
     * Note: In SUMIFS, sum_range comes FIRST!
     Example: =SUMIFS(I2:I51, B2:B51, "IndiGo", C2:C51, "T1")

3. AVERAGEIF & AVERAGEIFS:
   - Single Condition: =AVERAGEIF(criteria_range, criteria, [avg_range])
     Example: =AVERAGEIF(B2:B51, "Akasa Air", L2:L51)
   - Multiple Conditions: =AVERAGEIFS(avg_range, criteria_range1, crit1, ...)
     Example: =AVERAGEIFS(L2:L51, C2:C51, "T2", F2:F51, "International")

PART 6: LOOKUP & REFERENCE FUNCTIONS (VLOOKUP, INDEX/MATCH, XLOOKUP)
--------------------------------------------------------------------------------

1. VLOOKUP (Vertical Lookup - Traditional standard):
   Syntax: =VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
   - lookup_value  : Item you want to search for (must exist in Column 1 of table).
   - table_array   : The data table range (e.g. A2:M51).
   - col_index_num : Column number to return value from (1, 2, 3...).
   - [range_lookup]: ALWAYS use FALSE (or 0) for exact match!
   Example:
   =VLOOKUP("FL-105", A2:M51, 2, FALSE)
   -> Searches for "FL-105" in Col A and returns corresponding Airline from Col B.
   * Limitation: VLOOKUP cannot look to the left of the lookup column!

2. INDEX & MATCH (The Dynamic Gold Standard):
   - MATCH(lookup_val, lookup_array, 0): Finds row position index of an item.
   - INDEX(array, row_num, [col_num]): Returns data at that row & column.
   Combination Formula:
   =INDEX(B2:B51, MATCH("FL-105", A2:A51, 0))
   -> Looks up "FL-105" in A2:A51, finds row number, and fetches airline from B2:B51.
   * Superpower: Can look left, right, and is immune to column insertions.

3. XLOOKUP (Modern Superior Function in Excel 365 & Google Sheets):
   Syntax: =XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode])
   - Defaults to EXACT MATCH (no need to write FALSE).
   - Can search forwards or backwards and look left or right.
   Example:
   =XLOOKUP("FL-105", A2:A51, B2:B51, "Flight Not Found")

PART 9: AVIATION DATA ANALYSIS FORMULA RECIPES (PRACTICAL EXAMPLES)
--------------------------------------------------------------------------------

1. Passenger Load Factor (% Seat Occupancy):
   =ROUND((I2 / H2) * 100, 1) & "%"
   (Pax_Booked divided by Pax_Capacity, rounded to 1 decimal with % symbol)

2. Aircraft Revenue Estimate:
   =I2 * 4500
   (Pax_Booked multiplied by average ticket fare of Rs. 4,500)

3. On-Time Performance (OTP) 15-Minute Rule:
   =IF(L2 <= 15, "Punctual (OTP)", "Delayed")
   (Aviation industry standard: Flights within 15 min of schedule count as On-Time)

4. Baggage Ratio per Boarded Passenger:
   =ROUND(J2 / I2, 2)
   (Checked baggage count divided by actual passengers boarded)

5. Turnaround Delay Classification:
   =IF(L2=0, "Clean Departure", IF(L2<=30, "Minor Ramp Buffer", "Major Disruption"))
